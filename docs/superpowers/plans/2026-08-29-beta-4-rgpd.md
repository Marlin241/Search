# Beta — Plan 4 : RGPD minimum viable — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publier les pages Conditions d'utilisation / Politique de confidentialité, et donner à chaque utilisateur un moyen d'exporter ses données et de supprimer son compte (données en base + objets MinIO).

**Architecture:** Un module `app/auth/account_deletion.py` supprime, dans l'ordre des dépendances de clés étrangères, toutes les lignes rattachées à un utilisateur (directement ou via `diagnostics` / `saved_jobs` / `applications`), délie ses codes d'invitation, purge le préfixe MinIO `users/{id}/`, puis supprime la ligne `users`. `DELETE /auth/me` (ré-authentifié par mot de passe) l'appelle ; `GET /auth/me/export` renvoie un JSON de toutes les données de l'utilisateur. Deux pages Next statiques hors authentification servent les mentions légales.

**Tech Stack:** FastAPI, SQLAlchemy 2 (Core `delete()`), boto3 (MinIO), Next 16, pytest.

**Spec:** `docs/superpowers/specs/2026-08-29-lancement-beta-design.md` — §6 en entier (6.1 pages légales, 6.2 suppression de compte + audit cascades, 6.3 export).

## Global Constraints

- **Branche** `feature/beta-launch`, jamais `main`. Commits scopés.
- **Aucune migration** n'est *nécessaire* (toutes les FK `user_id` ont déjà `ondelete="CASCADE"` ; `invite_codes.used_by_user_id` a `ondelete="SET NULL"` — Beta 2). La suppression est faite **explicitement en code** pour être testable sous SQLite (où les FK ne sont pas appliquées) et lisible.
- **Ordre de suppression** = enfants avant parents. Ne jamais laisser d'orphelin (ligne `personalized_documents` sans `diagnostics`, etc.).
- **Datetimes naïfs UTC** ; `app.utils.time.utcnow()`.
- **Pages légales** : contenu rédigé ici en français ; **le fond juridique est validé par l'utilisateur** avant lancement (placeholder `[À CONFIRMER : …]` autorisé *uniquement* pour les faits que seul l'utilisateur connaît — raison sociale exacte, pays de l'hébergeur, email de contact).
- **`requirements.txt`** : aucune nouvelle dépendance.
- **Après modif backend testée** : rebuild du conteneur backend.
- Le lien `/conditions` et `/confidentialite` du formulaire d'inscription (Beta 2) doit fonctionner après ce plan.

```python
    def delete_prefix(self, prefix: str) -> int:
        deleted = 0
        try:
            paginator = self._client.get_paginator("list_objects_v2")
            for page in paginator.paginate(Bucket=self._bucket, Prefix=prefix):
                for obj in page.get("Contents", []):
                    self._client.delete_object(Bucket=self._bucket, Key=obj["Key"])
                    deleted += 1
        except (BotoCoreError, ClientError) as exc:
            raise ObjectStorageError(
                f"Échec de la suppression du préfixe '{prefix}'."
            ) from exc
        return deleted
```

## Task 2 : `delete_account(db, user, storage)`

**Files:**
- Create: `backend/app/auth/account_deletion.py`
- Test: `backend/tests/auth/test_account_deletion.py`

**Interfaces:**
- Consumes: tous les modèles ; `ObjectStorage.delete_prefix` (Task 1).
- Produces: `delete_account(db: Session, user: User, storage: ObjectStorage) -> None` — supprime, dans une transaction, dans cet ordre :
  1. `interviews` where `application_id in (apps de l'user)`
  2. `personalized_documents` where `diagnostic_id in (diags de l'user)`
  3. `interview_prep_dossiers` where `saved_job_id in (saved_jobs de l'user)`
  4. `applications`, `diagnostics`, `saved_jobs`, `saved_search`, `candidate_profiles`, `notified_listings` where `user_id = user.id`
  5. `job_search_request_logs`, `personalization_request_logs`, `compatibility_request_logs`, `interview_prep_request_logs`, `prefilled_form_request_logs`, `llm_call_logs`, `password_reset_token` where `user_id = user.id`
  6. `UPDATE invite_codes SET used_by_user_id = NULL WHERE used_by_user_id = user.id`
  7. `auth_attempts` where `identifier LIKE '{user.email.lower()}|%'` (best-effort — clé composée email|ip)
  8. `storage.delete_prefix(f"users/{user.id}/")` (échec loggé, non bloquant — cf. §Erreurs)
  9. `DELETE FROM users WHERE id = user.id`
  10. `db.commit()`

```python
import logging

from sqlalchemy import delete, select, update
from sqlalchemy.orm import Session

from app.models.application import Application
from app.models.auth_attempt import AuthAttempt
from app.models.candidate_profile import CandidateProfile
from app.models.compatibility_request_log import CompatibilityRequestLog
from app.models.diagnostic import Diagnostic
from app.models.interview import Interview
from app.models.interview_prep_dossier import InterviewPrepDossier
from app.models.interview_prep_request_log import InterviewPrepRequestLog
from app.models.invite_code import InviteCode
from app.models.job_search_request_log import JobSearchRequestLog
from app.models.llm_call_log import LlmCallLog
from app.models.notified_listing import NotifiedListing
from app.models.password_reset_token import PasswordResetToken
from app.models.personalization_request_log import PersonalizationRequestLog
from app.models.personalized_document import PersonalizedDocument
from app.models.prefilled_form_request_log import PrefilledFormRequestLog
from app.models.saved_job import SavedJob
from app.models.saved_search import SavedSearch
from app.models.user import User
from app.storage.client import ObjectStorage, ObjectStorageError

logger = logging.getLogger(__name__)


def delete_account(db: Session, user: User, storage: ObjectStorage) -> None:
    uid = user.id
    diag_ids = select(Diagnostic.id).where(Diagnostic.user_id == uid)
    sj_ids = select(SavedJob.id).where(SavedJob.user_id == uid)
    app_ids = select(Application.id).where(Application.user_id == uid)

    db.execute(delete(Interview).where(Interview.application_id.in_(app_ids)))
    db.execute(delete(PersonalizedDocument).where(PersonalizedDocument.diagnostic_id.in_(diag_ids)))
    db.execute(delete(InterviewPrepDossier).where(InterviewPrepDossier.saved_job_id.in_(sj_ids)))

    for model in (Application, Diagnostic, SavedJob, SavedSearch, CandidateProfile,
                  NotifiedListing, JobSearchRequestLog, PersonalizationRequestLog,
                  CompatibilityRequestLog, InterviewPrepRequestLog, PrefilledFormRequestLog,
                  LlmCallLog, PasswordResetToken):
        db.execute(delete(model).where(model.user_id == uid))

    db.execute(update(InviteCode).where(InviteCode.used_by_user_id == uid).values(used_by_user_id=None))
    db.execute(delete(AuthAttempt).where(AuthAttempt.identifier.like(f"{user.email.lower()}|%")))

    try:
        storage.delete_prefix(f"users/{uid}/")
    except ObjectStorageError:
        logger.exception("Object purge failed for user %s (rows still deleted)", uid)

    db.execute(delete(User).where(User.id == uid))
    db.commit()
```

@router.delete("/me", status_code=status.HTTP_204_NO_CONTENT)
def delete_me(payload: AccountDeleteIn, current_user: User = Depends(get_current_user),
              db: Session = Depends(get_db),
              storage: ObjectStorage = Depends(get_object_storage)) -> Response:
    if not verify_password(payload.password, current_user.hashed_password):
        raise HTTPException(status_code=status.HTTP_403_FORBIDDEN, detail="Mot de passe incorrect.")
    delete_account(db, current_user, storage)

@router.get("/me/export")

    data = build_account_export(db, current_user)  # helper local ou app/auth/account_export.py

        headers={"Content-Disposition": 'attachment; filename="mes-donnees.json"'},
